### UniClip

---

## About
UniClip is a shared clipboard where you can simply sync your clipboard to the website to make all the copied contents of one device available to another device who has joined your clipboard.
There is no authentication needed and it is a temporary session.
You can pair up devices by using a 4-digit random code generated whenever a device creates a new session.
Anyone can create or join a session.\
